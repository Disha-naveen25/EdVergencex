### AI-Powered Personal Tutor using NexusAI and Gradio

TutorBot is a simple AI tutor chatbot designed to help students understand technical and academic topics in an easy and structured way.

It uses the **NexusAI `nova-micro` model** through the OpenAI Python client and provides a simple web interface using **Gradio**.

---

##  Features

-  AI-powered academic tutor
-  Explains technical concepts in simple language
-  Provides structured exam-oriented answers
-  Gives real-world and programming examples
-  Highlights important exam points
-  Maintains conversation context
-  Interactive Gradio chat interface
-  Clear chat and conversation memory
-  Powered by NexusAI `nova-micro`

---

##  Technologies Used

- **Python**
- **NexusAI API**
- **OpenAI Python Client**
- **Gradio**
- **python-dotenv**
