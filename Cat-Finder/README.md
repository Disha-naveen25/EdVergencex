#  Random Cat Finder

A simple and interactive web application that displays a random cat image every time the user clicks the **Get Another Cat** button.

The application uses the **Cat API** to fetch random cat images and is built using **Python and Streamlit**. It is deployed using **Streamlit Community Cloud**.

##  Live Demo

Click this to view the live application - https://cat-finder-miniproject2.streamlit.app/


---

##  Project Overview

Random Cat Finder is a beginner-friendly web application developed as a frontend/API-based mini project.

The application allows users to:

- View a random cat image.
- Fetch a new cat image with a single click.
- Interact with a simple and user-friendly interface.
- Access the application directly through a web browser using the deployed Streamlit link.

The project demonstrates how an external REST API can be integrated into a Python-based web application.

---

##  Features

-  Random cat image generation
-  Fetch a new image with one click
